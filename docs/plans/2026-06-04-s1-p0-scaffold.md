# S1 · P0 — Monorepo Scaffold + Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the empty `pipeline/` + `backend/` + `frontend/` monorepo skeleton with full tooling (uv, ruff, mypy, pytest; pnpm, Vite, TS, Tailwind, eslint, vitest; Docker Compose; CI), all green, without touching the still-running `demo/`.

**Architecture:** Three independent packages at the repo root. Python packages use uv + `src/` layout. Frontend is a Vite React-TS SPA. A `docker-compose.yml` runs backend + frontend locally; GitHub Actions runs lint + typecheck + test per package. This phase ports no logic — it only creates the skeleton each later phase fills in.

**Tech Stack:** Python 3.12 · uv · ruff · mypy · pytest · FastAPI · pydantic-settings · Node 22 · pnpm · Vite · React · TypeScript · Tailwind · eslint · vitest · Docker · GitHub Actions

**Prerequisites (verified present):** `python3 --version` ≥ 3.12 · `uv --version` ≥ 0.10 · `node --version` ≥ 22. Enable pnpm once: `corepack enable pnpm`.

**Reference:** spec at `docs/specs/2026-06-04-phase2-s1-rearchitecture-design.md` (§3 structure, §5 tooling). `demo/` is untouched by this plan.

```python
from __future__ import annotations

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_prefix="BUSAPI_", env_file=".env")

    db_path: str = "db/bus.duckdb"
    cors_origins: list[str] = ["http://localhost:5173"]


settings = Settings()
```

`backend/src/busanalytics_api/main.py`:
```python
"""FastAPI application factory."""
from __future__ import annotations

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from .config import settings


def create_app() -> FastAPI:
    app = FastAPI(title="HCMC Bus Analytics API", version="0.1.0")
    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.cors_origins,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    @app.get("/api/healthz")
    def healthz() -> dict[str, str]:
        return {"status": "ok"}

    return app


app = create_app()
```

### Task 6: GitHub Actions CI (lint + typecheck + test per package)

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Write the CI workflow**

`.github/workflows/ci.yml`:
```yaml
name: CI

on:
  push:
  pull_request:

jobs:
  pipeline:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: pipeline
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v3
      - run: uv sync --extra dev
      - run: uv run ruff check .
      - run: uv run mypy
      - run: uv run pytest -q

  backend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v3
      - run: uv sync --extra dev
      - run: uv run ruff check .
      - run: uv run mypy
      - run: uv run pytest -q

  frontend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: frontend
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: corepack enable pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint
      - run: pnpm typecheck
      - run: pnpm test
```
