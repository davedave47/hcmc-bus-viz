# Technology logos

Section §3.2 Analytical Stack uses these logos. Download each from
the official source as PNG (transparent background, around 256–512 px
on the long side) and save with the filename below.

| File             | Source                                                                 |
|------------------|------------------------------------------------------------------------|
| `duckdb.png`     | <https://duckdb.org/images/logo-dl/DuckDB_Logo-stacked.png>            |
| `polars.png`     | <https://github.com/pola-rs/polars-static/blob/master/logos/polars-logo-dimmed.png?raw=true> |
| `jupyter.png`    | <https://jupyter.org/assets/homepage/main-logo.svg>  *(or PNG export)* |
| `streamlit.png`  | <https://streamlit.io/images/brand/streamlit-mark-color.png>            |
| `pydeck.png`     | <https://deck.gl/images/logo/deckgl.png>                                |
| `plotly.png`     | <https://images.plot.ly/logo/new-branding/plotly-logomark.png>          |

LaTeX picks up `.png`, `.pdf`, `.jpg` automatically — drop any of
these formats in this folder under the names above and the report
will compile.
