\addcontentsline{toc}{chapter}{Appendix C --- Image and Diagram Inventory}

This appendix is the single master inventory of every image,
screenshot, diagram, and chart this report needs. The body of
the report uses the \texttt{\textbackslash imageplaceholder}
macro to leave a labelled box wherever a visual asset will go;
this appendix collects every such placeholder in one place with
the capture instructions. The intent is that the author can
work through this appendix once, photograph or export every
asset, save each to the listed path, and the placeholders in
the body will then be replaced wholesale.

\paragraph{Workflow recommendation.}
To replace the placeholders with real images: (i)~capture every
asset in this table; (ii)~save each to the listed path;
(iii)~edit the corresponding section file to swap
\texttt{\textbackslash imageplaceholder}$\{$\dots$\}$ for
\texttt{\textbackslash includegraphics[width=...]{path}};
(iv)~re-run \texttt{xelatex} + \texttt{biber} +
\texttt{xelatex} $\times$ 2.
