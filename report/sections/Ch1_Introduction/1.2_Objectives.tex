\section{Objectives}
\label{sec:intro:objectives}

The project sets the following objectives for Phase One.

\begin{enumerate}
\item Establish the analytical capabilities the existing tools for the
Ho Chi Minh City bus network do not provide, and identify the user
roles those capabilities would serve.
\item Survey the peer-reviewed research on bus operational analytics,
public-transit visualization, and analytical-chart design, and
identify the methods and primitives applicable to the present
project.
\item Specify a data architecture, a catalog of analytical themes, a
visualization technique per theme, and an interaction model that
together compose the proposed analytical platform.
\item Implement the data-preprocessing pipeline to the level required
by the proposed architecture, and demonstrate the platform's design
through a running prototype and the platform's
initial evaluation against the stated requirements.
\item Plan the Phase Two implementation in sufficient detail to
commence implementation work without further design effort.
\end{enumerate}
