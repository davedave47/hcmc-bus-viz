\section{Solution Overview}
\label{sec:solution:overview}

The proposed system is an analytical platform over the preprocessed Ho Chi
Minh City bus data. Four design components compose the analytical
surface. A layered analytical warehouse sits over the preprocessed data
and produces a fixed set of aggregate tables. The analytical content is
grouped into a fixed catalogue of six thematic views, each addressing one
class of analytical question and reading from one cluster of aggregate
tables. Within each theme, every visualisation is matched to a single
primitive chart type selected to fit the question the chart answers,
with rejected alternatives recorded as part of the design record. An
interaction model then connects the visualisations across each thematic
view and provides a uniform response to user clicks on analytical
entities.

Figure~\ref{fig:solution:overview} places the platform in its
deployment context. External data sources sit on the left; the
platform boundary is the central box containing the Medallion
warehouse and the analytical surface; the three user roles sit on the
right. The diagram makes the system boundary explicit: real-time
telemetry, the metro timetable, and OpenStreetMap road data are
external dependencies, not part of the platform; the natural-language
query capability is an external team's surface that will eventually
plug into the same warehouse.
